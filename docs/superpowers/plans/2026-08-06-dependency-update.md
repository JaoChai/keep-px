# Dependency Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring Keep-PX dependencies current — React Router 8, all safe minor/patch bumps on both stacks, Go 1.26.5, and `stripe-go` from v82 to v86 — without changing any application behavior.

**Architecture:** Seven tasks, ordered by ascending risk, each ending in its own commit. Tasks 1–3 are independent and can ship in any order. Tasks 4–6 walk `stripe-go` forward one major at a time so any failure is attributable to a single version. Task 7 syncs documentation. No production code is refactored beyond what a dependency forces.

**Tech Stack:** Go 1.26.5 · chi v5 · pgx v5 · stripe-go v86 · React 19 · React Router 8 · Vite 7 · TypeScript 5.9 · Vitest 4 · Playwright 1.62 · PostgreSQL 17

**Spec:** `docs/superpowers/specs/2026-08-06-dependency-update-design.md`

## Global Constraints

- **Branch:** all work happens on `chore/dependency-update-2026-08`, already created and holding the spec commit.
- **Do NOT upgrade these — deliberately deferred:** `vite` (stays 7.x), `typescript` (stays 5.9.3), `eslint` and `@eslint/js` (stay 9.x), `eslint-plugin-react-refresh` (stays 0.4.x), `@vitejs/plugin-react` (stays 5.x), `@types/node` (stays 24.x), `dotenv` (stays 16.x), `globals` (stays 16.x), `jsdom` (stays 28.x), `lucide-react` (stays 0.575.x), `react-doctor` (stays 0.2.x).
- **No behavior change.** Every edit must trace to a dependency requirement. Do not refactor working code, do not "improve" adjacent lines, do not add features or tests beyond what a task specifies (CLAUDE.md §3).
- **Commit style:** Conventional Commits — commitlint runs on `commit-msg` via husky. A malformed message is rejected.
- **Pre-commit hook:** lint-staged runs `eslint --fix` on staged `frontend/src/**/*.{ts,tsx}`. Expect it to run; it is not an error.
- **golangci-lint version:** v2.12.1, pinned in CI. Use that exact version locally.
- **Integration tests** need a real Postgres. Start it with `docker compose up -d postgres` from the repo root, then export `TEST_DATABASE_URL=postgres://pixlinks:pixlinks_dev@localhost:5432/pixlinks?sslmode=disable`.
